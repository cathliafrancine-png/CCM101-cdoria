# AWS Research

## Brief Overview

Amazon Web Services (AWS) is a cloud computing platform that provides a wide range of on-demand IT resources and services over the internet. These include computing, storage, databases, networking, security, analytics, and other cloud capabilities. AWS allows organizations to provision resources as needed and use a pay-as-you-go pricing model, making it suitable for startups, enterprises, and other organizations. AWS began offering cloud infrastructure services in 2006.

## Global Infrastructure

AWS operates a global cloud infrastructure consisting of geographic Regions and Availability Zones. AWS currently spans 39 Geographic Regions and 124 Availability Zones. Each Region contains multiple isolated Availability Zones that are connected through low-latency and high-bandwidth networking. This infrastructure helps AWS provide reliable, scalable, and highly available cloud services to customers around the world.

## Cloud Management Console

The AWS Management Console is a web-based interface used to access and manage AWS cloud services. It allows users to search for services, create and configure cloud resources, manage users and permissions, monitor service usage, and manage billing. The console provides a centralized interface for managing AWS resources across different Regions.

## Four Core Services

### 1. Amazon EC2

Amazon Elastic Compute Cloud (Amazon EC2) provides scalable computing capacity in the AWS Cloud. It allows users to launch and manage virtual servers, called instances, with different configurations based on their computing requirements.

### 2. Amazon S3

Amazon Simple Storage Service (Amazon S3) is an object storage service designed to store and retrieve large amounts of data. It can be used for backups, application data, media files, websites, and other types of digital information.

### 3. Amazon RDS

Amazon Relational Database Service (Amazon RDS) is a managed service that makes it easier to set up, operate, and scale relational databases in the cloud. It helps organizations manage database workloads without having to handle many of the underlying administrative tasks.

### 4. Amazon VPC

Amazon Virtual Private Cloud (Amazon VPC) allows users to create a logically isolated virtual network within AWS. It provides control over networking resources such as IP addresses, subnets, routing, and security settings for cloud applications.

## Three Advantages

1. **Wide Range of Services** – AWS provides a broad selection of cloud services for computing, storage, databases, networking, security, analytics, artificial intelligence, and other business needs.

2. **Scalability and Flexibility** – Organizations can increase or decrease their cloud resources based on changing workloads and business requirements.

3. **Global Infrastructure** – AWS provides infrastructure across many geographic Regions and Availability Zones, allowing organizations to deploy applications closer to their users and design highly available systems.

## Typical Enterprise Use Cases

AWS is commonly used by enterprises for hosting websites and business applications, storing and backing up large amounts of data, running databases, and supporting data analytics. Organizations can also use AWS for application development, machine learning, disaster recovery, and scalable global applications. Its wide range of services allows businesses to build and manage different types of workloads without maintaining all of the physical infrastructure themselves.
