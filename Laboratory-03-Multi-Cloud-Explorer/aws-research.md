# AWS Research

## Brief Overview

Amazon Web Services (AWS) is a cloud computing platform that provides a wide range of on-demand IT resources and services over the internet. These include computing, storage, databases, networking, security, analytics, and other cloud capabilities. AWS allows organizations to provision resources as needed and use a pay-as-you-go pricing model, making it suitable for startups, enterprises, and other organizations. AWS began offering cloud infrastructure services in 2006.
