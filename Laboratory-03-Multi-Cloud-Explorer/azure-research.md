# Azure Research

## Brief Overview

Microsoft Azure is a cloud computing platform that provides a wide range of cloud services for computing, storage, networking, databases, analytics, artificial intelligence, and application development. Azure allows organizations to build, deploy, and manage applications and services using Microsoft's global cloud infrastructure. It supports businesses of different sizes and provides services that can be scaled according to their needs.

## Global Infrastructure

Azure provides over 70 regions globally across different geographies. An Azure region consists of one or more datacenters connected through high-capacity, fault-tolerant, and low-latency networks. Many Azure regions provide Availability Zones, which help organizations design applications with greater redundancy and resilience. Azure geographies also support data residency and compliance requirements.

## Cloud Management Console

The Azure portal is a web-based management interface used to create, configure, monitor, and manage Azure resources and services. It provides a centralized interface where users can manage virtual machines, databases, storage, networking, applications, and other cloud resources. The portal also provides tools for monitoring resources, managing access, and viewing cloud usage.

## Four Core Services

### 1. Azure Virtual Machines

Azure Virtual Machines provides on-demand, scalable computing resources in the cloud. It allows organizations to run Windows or Linux virtual machines without purchasing and maintaining physical servers.

### 2. Azure Blob Storage

Azure Blob Storage is an object storage service designed to store large amounts of unstructured data. It can be used for documents, images, videos, backups, application data, and other digital files.

### 3. Azure SQL Database

Azure SQL Database is a fully managed relational database service based on the Microsoft SQL Server database engine. It provides features for scalability, availability, security, and database management without requiring organizations to maintain the underlying infrastructure.

### 4. Microsoft Entra ID

Microsoft Entra ID is a cloud-based identity and access management service. It helps organizations manage user identities and control access to applications and resources while supporting authentication and security requirements.

## Three Advantages

1. **Microsoft Integration** – Azure integrates closely with Microsoft products and technologies such as Windows Server, Microsoft 365, Active Directory, and SQL Server.

2. **Global Availability** – Azure provides a large global infrastructure with many regions, allowing organizations to deploy services closer to users and meet data residency requirements.

3. **Scalability and Flexibility** – Azure resources can be scaled according to workload requirements, allowing organizations to adapt their cloud infrastructure as their needs change.

## Typical Enterprise Use Cases

Azure is commonly used by enterprises for hosting business applications, migrating Windows Server workloads, managing databases, storing organizational data, and supporting application development. Organizations can also use Azure for artificial intelligence, analytics, disaster recovery, virtual desktops, and hybrid cloud environments. Its integration with Microsoft's existing technologies makes Azure suitable for organizations that already rely on Microsoft products and services.
