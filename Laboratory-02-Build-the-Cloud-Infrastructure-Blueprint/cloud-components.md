# Cloud Infrastructure Components

## Compute Resources

### Purpose
Compute resources provide the processing power needed to run commands, applications, and workloads.

### Importance in Cloud Computing
Compute resources are important in cloud computing because they provide the processing capacity needed to run applications and perform tasks.

### Relation to the KillerCoda Linux Environment
The KillerCoda Linux environment has 1 CPU core with an Intel Xeon E312xx processor. This provides the processing power needed to execute Linux commands and perform the laboratory activities.

## Storage Resources

### Purpose
Storage resources provide space for storing the operating system, files, applications, and other data.

### Importance in Cloud Computing
Storage resources are important in cloud computing because data and applications need space to be stored and accessed when needed.

### Relation to the KillerCoda Linux Environment
The KillerCoda Linux environment has a 19G disk capacity. The environment also has mounted file systems such as `/`, `/boot`, and `/boot/efi` for storing and supporting the Linux system files.

## Networking Resources

### Purpose
Networking resources provide connectivity that allows systems and applications to communicate and exchange data.

### Importance in Cloud Computing
Networking resources are important in cloud computing because they allow cloud resources and services to communicate with users and other systems.

### Relation to the KillerCoda Linux Environment
The KillerCoda Linux environment has the IP addresses `172.30.2.1` and `172.17.0.1`. These addresses show the network addresses available in the Linux environment for network communication.

## Operating System

### Purpose
The operating system manages system resources and provides the environment needed to run applications and commands.

### Importance in Cloud Computing
The operating system is important in cloud computing because it manages the resources of a cloud server and provides the environment where applications and services run.

### Relation to the KillerCoda Linux Environment
The KillerCoda Linux environment uses Ubuntu 24.04.4 LTS. It provides the Linux environment used to perform the laboratory activities and execute the required commands.
