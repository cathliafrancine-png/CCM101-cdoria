# Cloud Provider Comparison

## Infrastructure Services Comparison

| Infrastructure Component | AWS | Microsoft Azure | Google Cloud Platform |
|---|---|---|---|
| Compute | Amazon EC2 | Azure Virtual Machines | Google Compute Engine |
| Storage | Amazon S3 | Azure Blob Storage | Google Cloud Storage |
| Networking | Amazon VPC | Azure Virtual Network | Google Cloud VPC |
| Identity and Access Management (IAM) | AWS IAM | Azure RBAC | Google Cloud IAM |

## Guide Questions

### 1. Which cloud provider offers the broadest range of services? Explain your answer.

AWS offers the broadest range of cloud services among the three providers. It provides many services for computing, storage, networking, databases, security, analytics, and other cloud needs, giving organizations more options depending on their requirements.

### 2. Which cloud platform would you recommend for an organization that primarily uses Microsoft products? Why?

I would recommend Microsoft Azure because it works well with Microsoft products and services. This can make it easier for an organization that already uses tools such as Windows, Microsoft 365, and other Microsoft technologies to connect and manage its cloud resources.

### 3. Which platform is widely recognized for Artificial Intelligence (AI), Machine Learning (ML), and Kubernetes services?

Google Cloud Platform is widely recognized for its AI, machine learning, and Kubernetes services. It provides Google Kubernetes Engine (GKE) for running Kubernetes workloads and also offers AI and machine learning services for developing and deploying applications.

### 4. What similarities did you observe among the three cloud providers?

The three cloud providers offer similar core infrastructure services, including compute, storage, networking, and identity and access management. Although the names of their services are different, they all provide these resources to help organizations run applications, store data, connect systems, and control access to cloud resources.
