# Mission Reflection

## 1. Which cloud infrastructure component do you think is the most important? Why?

For me, the compute resource is the most important component because it provides the processing power needed to run commands, applications, and workloads. In the laboratory, I saw how the CPU of the Linux environment was used to execute commands and perform the activities.

## 2. How does Linux support cloud computing?

Linux supports cloud computing by providing an operating system environment where cloud resources, applications, and services can run. In this activity, I used the Ubuntu Linux environment in KillerCoda to inspect system resources and execute commands. It helped me understand how a cloud environment can be managed through the command line.

## 3. Why is technical documentation important before deploying infrastructure?

Technical documentation is important because it keeps information about the infrastructure organized and easier to understand. It also helps prevent mistakes because important details such as resources, commands, and configurations are recorded. In this laboratory, documenting the system information and cloud infrastructure made it easier to review the work.

## 4. What new skills did you learn during this laboratory activity?

I learned how to use basic Linux commands to inspect the operating system, kernel, CPU, memory, disk, hostname, and IP addresses. I also learned how to compare equivalent services from AWS, Microsoft Azure, and Google Cloud Platform. Aside from that, I practiced creating a simple cloud infrastructure diagram and documenting my work using Markdown and GitHub.

## 5. How has your GitHub portfolio improved after completing this mission?

My GitHub portfolio improved because it now contains a more complete laboratory project with system documentation, a cloud provider comparison, a cloud infrastructure diagram, and a reflection. It shows the work I completed and how I documented it. This makes my repository more organized and gives me a better example of how technical work can be presented.
