# Laboratory 05 - Cloud Data Engineer

## Mission Overview

This laboratory focused on deploying and interacting with an object storage server using Docker and MinIO. The MinIO server was deployed in a KillerCoda Ubuntu Playground and accessed through its web-based console. A storage bucket was created and a sample file was uploaded to demonstrate object storage operations.

## Objectives

* Deploy an object storage server using Docker.
* Configure MinIO using environment variables.
* Access the MinIO Web Console through port 9001.
* Create an object storage bucket named `client-photos`.
* Upload a sample file to the created bucket.
* Document the technical deployment and configuration steps.

## Tools Used

* KillerCoda Ubuntu 24.04 Playground
* Docker
* MinIO
* MinIO Web Console
* Web Browser

## Skills Learned

* Deploying applications using Docker containers.
* Working with Docker images and container ports.
* Configuring applications using environment variables.
* Accessing a web service through a custom port.
* Creating and managing object storage buckets.
* Uploading objects to an S3-compatible object storage server.
* Documenting technical deployment procedures using Markdown.
